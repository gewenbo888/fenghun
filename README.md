# Wind Soul Quiz · 戈苏御 · 风魂人格测试

在喧嚣宇宙中，测测你是哪一种纯粹之风？通过 8 道情境哲思题，生成专属五维风魂雷达图、朱红风魂印章与高清朋友圈/小红书分享海报。
